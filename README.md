# ETF 知识卡

把知识库里的 **149 张 ETF / 投资知识卡**装进一台单文件 App：每天推一张，可翻面看原文、可标记已学、按体系分类浏览。

---

## 一、怎么用

### 电脑（现在就能用）
双击 `ETF知识卡.html`，浏览器直接打开。

### 手机
| 方式 | 操作 | 说明 |
|---|---|---|
| **A. GitHub Pages（推荐）** | 打开 **https://123yyy123-sky.github.io/etf-cards/** | 点开即用；可「添加到主屏幕」变成图标；内容改了重新推送即更新 |
| B. 传文件 | 把 `ETF知识卡.html` 发到手机，存下来后用**浏览器**打开 | ⚠️ **微信 / 飞书内置浏览器不渲染 .html**，点开会白屏或提示下载 —— 这就是「手机打不开」的常见原因 |
| C. 局域网 | 电脑跑 `python -m http.server`，手机同 WiFi 访问 | 不出门能用 |

---

## 二、功能

| 页 | 内容 |
|---|---|
| **今日** | 每天自动推一张。优先推**到期待复习**的卡，否则从**未学**里按天轮转 |
| ↳ 展开详解 | 点「展开详解」看这张卡的完整原文（标题 / 表格 / 列表 / 公式全部保留） |
| ↳ 标记已学 | 记进度，并在 **1 / 3 / 7 / 15 / 30 / 60 天**后自动回到复习队列（间隔重复） |
| **分类** | 5 大组 15 小类，可展开；点任意一张直接看 |
| **进度** | 总进度、各分组进度条、连续打卡天数、待复习张数 |

学习记录存在**手机浏览器本地**（不上传、不需要账号）。换浏览器或清缓存会丢。

## 四、知识库更新后

双击 `更新卡片.bat` 重新生成即可。**已学记录不会丢**——卡片用源文件路径做唯一标识，新增卡片不会打乱已有进度。

## 五、文件清单

| 文件 | 作用 |
|---|---|
| `ETF知识卡.html` | **成品**，双击即用（单文件，离线可读，约 870KB） |
| `cards.json` | 抽取出来的卡片数据（149 张 / 33 万字） |
| `app-template.html` | 界面模板（含数据占位符） |
| `build/extract.py` | 从知识库抽取卡片 → cards.json |
| `build/build.py` | cards.json + 模板 → 单文件 HTML |
| `更新卡片.bat` | 上面两步一键跑 |

## 七、仓库与发布（GitHub Pages）

| 项 | 值 |
|---|---|
| 仓库 | `https://github.com/123yyy123-sky/etf-cards` |
| 网址 | `https://123yyy123-sky.github.io/etf-cards/` |
| 发布源 | `main` 分支的 `/docs` 目录 |
| 发布文件 | `docs/index.html`（由 `build/build.py` 与本机单文件版一并生成，两者内容一致） |

**更新流程**
```powershell
python build\build.py
ren docs\`   # 可选
```
```
git add -A
git commit -m "更新卡片"
git push
```
约 1 分钟后手机刷新即最新。

> ⚠️ **本机 git 连不上 GitHub 的已知原因**：`~/.gitconfig` 里有
> `http.https://github.com/.proxy = http://127.0.0.1:65533`，该代理已失效。
> 表现为 `git push` 报 `Failed to connect to github.com:443 over proxy`。
> 解决：把那两行删掉（走直连即可），或改成当前可用的代理端口。
